🌍 ¿Qué es una página web?

```
Inicio ¿Qué es la web? HTML y CSS Publicación
```

💡 Explicación

```

Una página web es un documento que se visualiza en Internet mediante un navegador.

Un sitio web es un conjunto de páginas web conectadas entre sí.

Internet es una red global que conecta millones de ordenadores.

🔎 Cómo funciona

  • El navegador hace una petición
  • El servidor responde
  • Se envían datos por la red
```
